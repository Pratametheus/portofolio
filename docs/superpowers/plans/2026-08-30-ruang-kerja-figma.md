# "Ruang Kerja" Figma Redesign — Implementation Plan (Plan A of 2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> This plan builds the **Figma design + assets**. The site code rebuild is **Plan B**, written after the Figma output here is approved by Ferry.

**Goal:** Turn the near-empty portfolio Figma file into a 3-page deliverable — a two-theme design system, and full night + light desktop mockups — plus an original character and icon set, all generated by us, with the "Karya terpilih" section shown as real images.

**Architecture:** Work entirely through the Figma MCP (`mcp__claude_ai_Figma__*`) and Canva MCP (`mcp__claude_ai_Canva__*`). Colours live in one Figma variable collection with two modes (`Night`, `Light`); every fill is a variable alias, never a raw hex. Assets: Canva AI generates the character and hero raster art; the UI icon set is drawn as vectors in Figma. Verification is visual — `get_screenshot` and `get_metadata` after each task, against explicit acceptance checks.

**Tech Stack:** Figma MCP server, Canva MCP server, Figma variables/modes, Figma components + variants. No code in this plan.

**Spec:** `docs/superpowers/specs/2026-08-30-ruang-kerja-design.md` (read it and `docs/spec/FASE-3-Spec-Arsitektur.md` before starting)

## Global Constraints

Copied verbatim from the spec — every task inherits these:

- **Figma file:** `0bLl0krxjy0mofkU4vCSe5` ("Ferry Andhika Pratama — Portfolio Website"). It currently holds one page, `00 · Cover` (node `0:1`, frame `3:8`). Delete nothing that is referenced.
- **Exactly 3 pages** when done: `Design System`, `Portfolio · Night`, `Portfolio · Light`. No more.
- **No raw hex on any fill/stroke** where a token exists — every colour is a variable alias.
- **Fonts:** only Inter Tight (display), Inter (body), JetBrains Mono (data/code). No other family anywhere.
- **Mono is semantic:** every number, date, file size, year, DOI, and technical term uses JetBrains Mono.
- **Night is the default theme.** Light is the second mode.
- **Night tokens:** bg `#0A0A0B` · surface `#131316` · surface-2 `#1B1B1F` · border `#26262B` · fg `#EDEDEF` · fg-muted `#9B9BA3` · accent `#FACC15` · accent-dim `#FACC1522` · ring `#FACC15`.
- **Light tokens:** bg `#F7F3EC` · surface `#EFE9DE` · surface-2 `#E7DFD1` · border `#DED4C2` · fg `#2B2925` · fg-muted `#6B6459` · accent `#B7791F` · accent-dim `#B7791F1F` · ring `#B7791F`.
- **Type scale (px):** 12, 14, 16, 18, 20, 24, 32, 44. Weights 400 / 500 / 600. Body 16 px / 1.6.
- **Spacing (px):** 4, 8, 12, 16, 24, 32, 48, 64, 96. **Radius:** 4 tag · 8 button/input · 12 card · 16 image-card/modal. Border width 1.
- **Contrast minimums:** fg on bg ≥ 7:1 · fg-muted on bg ≥ 4.5:1 · accent on bg ≥ 4.5:1 · any text on accent-dim ≥ 4.5:1.
- **Interactive targets ≥ 24 px.**
- **Desktop frames are 1440 wide.** Sidebar rail ~280 px.
- **Assets are ours:** no template icon packs, no stock art. Canva-generated or Figma-drawn only.
- **Motion notes belong in frame descriptions, not animations:** theme cross-fade 200 ms; key-ring 40 s/rotation, static SVG under `prefers-reduced-motion`.
- **Nav (id → en):** Beranda→Home, Tentang→About, Karya→Work, Riset→Research, Pencapaian→Achievements, Buku Tamu→Guestbook, Kontak→Contact, Links→Links.
- **Case-study slugs (locale-independent):** `siakad-informatika`, `city-courier`, `mochitoon`.
- **City Courier art source:** Figma file `wY01agep1Pyz0cpVlVEszO`, page `Asset`, frame `2007:737` (contains `Logo City Courier`, scooter-shaped key, courier-with-magnifying-glass, hand-truck, "COMING SOON", etc.).
